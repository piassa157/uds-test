# Filesmove Angular Views

## Rodar em desenvolvimento

```bash
npm install
npm start
```

A aplicação ficará disponível em `http://localhost:4200` e fará proxy de `/api` para `http://localhost:8080`.

## Build

```bash
npm run build
```

## Rodar via Docker Compose (integrado)

Após subir `docker compose up --build`, o front ficará em `http://localhost:4200`.
